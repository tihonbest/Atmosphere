# Atmosphere

Минималистичные цифровые часы и погода в одном адаптивном интерфейсе.

## Возможности

- Большие часы с секундами и локальной датой.
- Текущая погода: температура, ощущается как, описание, ветер, влажность и вероятность осадков.
- Почасовой прогноз на ближайшие часы.
- Поиск города и определение местоположения браузером.
- Переключение °C / °F.
- Адаптация под телефон, планшет, компьютер и альбомную ориентацию.
- Последний выбранный город сохраняется в браузере.

## Источники данных

- [Open-Meteo Forecast API](https://open-meteo.com/) — прогноз погоды.
- [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api) — поиск городов.

API-ключ и регистрация не требуются. Для геолокации браузеру может понадобиться разрешение пользователя. GitHub Pages работает по HTTPS.
